# public/

Files here are served from the site root.

## resume.pdf — REQUIRED

The header, footer, about page and contact page all link to `/resume.pdf`.
Drop your résumé in this folder with exactly that filename.

Until you do, those links 404. The previous site worked around this by
generating a placeholder `.txt` file on click, which downloaded something
called `Ansh_Yadav_Resume.txt` containing the words "This is a placeholder
resume" — that has been removed.
